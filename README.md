# ZAINTEA Business Tracker

A full-featured business tracking dashboard built with React, Vite, and Tailwind CSS.

## Features

- **Dashboard** — Live KPIs, sales vs expense charts, daily profit, balance growth
- **Daily Entry** — Add/edit/delete daily sales, expenses, card/cash split, expense breakdown
- **Analytics** — Day-of-week patterns, rolling 7-day profit trend, expense pie chart
- **Settlement** — Record cash withdrawals, bank deposits, supplier payments
- **Goals & Tips** — Set daily/monthly targets, business improvement recommendations
- **Settings** — Export CSV/JSON, data reset

## Setup

### Prerequisites
- Node.js 18+ installed
- npm or yarn

### Installation

1. Open terminal (Command Prompt or PowerShell) and navigate to this folder:
   ```
   cd C:\Users\ashik\Desktop\Work\Bytrix\zaintea-business-tracker
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm run dev
   ```

4. Open your browser and go to:
   ```
   http://localhost:5173
   ```

### Build for production
```
npm run build
npm run preview
```

## Data Storage
All data is stored in your browser's localStorage — no internet connection required, fully private.

## Tech Stack
